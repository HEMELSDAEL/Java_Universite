# Ceci est le TP2 de POO fait par HEMELSDAEL Alexandre et LECLERC Laura

Ce TP avait pour but de nous faire appliquer les différentes méthodes de compilation et d'exécution (avec et sans paramètres) en java

Voici la commande utilisée pour générer la documentation : `javadoc src/nom_du_fichier.java -d docs`
Voici la commande utilisée pour compiler les classes : `javac -sourcepath src src/nom_du_fichier.java -d classes`
Voici la commande utilisée pour exécuter les programmes Main : `java -classpath classes nom_du_fichierMain`
